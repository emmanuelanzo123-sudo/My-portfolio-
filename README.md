# Personal Portfolio Website – Emmanuel Anzo

A modern, responsive personal portfolio website showcasing my journey as a Technology Enthusiast and Digital Innovator.

The website highlights my skills, projects, services, and interests in technology, with a focus on Artificial Intelligence, Web Development, UI/UX Design, Programming, and Technology Training.

### Features
- Modern and responsive user interface.
- Professional introduction and About section.
- Skills and services showcase.
- Featured projects and portfolio section.
- Contact form powered by FormSubmit for email enquiries.
- Mobile-friendly navigation.

### Technologies Used
- HTML5
- CSS3
- JavaScript

### Purpose
To establish my professional digital presence, showcase my technical abilities, document my learning journey, and connect with potential clients, collaborators, and opportunities.
